Connect the shop

One-time setup — this page publishes to the live site through your GitHub account.

How it works: you paste a private access token below. It’s saved only in this browser and sent only to GitHub.

  1. Sign in to GitHub and open New fine-grained personal access token.
  2. Give it any name (for example shop manager) and an expiry you’re comfortable with.
  3. Under Repository access, choose Only select repositories → SavannahSidle/WorkofHeart.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else alone.
  5. Generate the token, copy it, and paste it below.

If it ever stops working, come back here and paste a fresh one.
